# Publication / packaging status

This archive is a reviewable **source snapshot** prepared from a locally exported Git revision. It is **not** the runnable CrossMix update package and should not be installed onto an SD card as-is.

The upstream codebase includes third-party precompiled libraries, launcher ELF files, fonts and screenshots. Those files were intentionally removed here until their redistribution conditions, provenance and compatible binary dependencies can be checked for the intended release. The original upstream credits, notices and GPL-3.0 text are preserved.

The CrossMix Turquoise launcher patch requires the compatible pre-existing CrossMix runtime and APK installer. If you want to publish an installable GitHub Release, submit the actual verified **installer/archive produced by your build** for a separate audit. A source archive cannot prove that installation, controller input, performance or saves work on other devices.

Hardware known issues from the supplied project evidence: L2/R2 not functioning, performance goal unmet, some texture/particle modifications experimental; most recent turquoise revision had only automated tests. Do not claim that login, multiplayer, Microsoft services or all controller actions are supported until tested.

The original source ZIP was not accompanied by the Git history. Link back to DankMiimer and preserve contributions. Do not claim to have authored the underlying handheld port from scratch.
